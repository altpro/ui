Custom properties

Every button reads these. Override on .btn globally or inline on one element.

.btn {
  --btn-bg       /* fill */
  --btn-fg       /* text on fill */
  --btn-accent   /* text + border for outlined and ghost */
  --btn-outline   /* outlined variant's border colour */
  --btn-hover    /* hover fill, derived from --btn-bg by default */
  --btn-radius   /* defaults to --radius */
  --btn-h --btn-px --btn-text
}
