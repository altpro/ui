Range

.range on a native <input type="range">. Arrow keys, Home, End, Page Up and Page Down all work because the browser owns the control. No JavaScript.

In a field

A <label for> names it. An <output> shows the value; one line of script keeps it current, since CSS cannot read the value.

In steps of £50.

<div class="field">
  <label for="volume" class="flex justify-between">Volume <output for="volume">40</output></label>
  <input class="range" id="volume" type="range" min="0" max="100" value="40"
         oninput="this.previousElementSibling.lastElementChild.value = this.value">
</div>

Accent

The thumb is --range-accent, primary by default. Set it inline for one slider.

Custom properties

.range {
  --range-track    /* track fill, muted */
  --range-accent   /* thumb, primary */
  --range-ring     /* focus ring, --color-ring */
  --range-h        /* track height, 0.5rem */
  --range-thumb    /* thumb diameter, 1.25rem */
  --range-radius   /* track corners, defaults to --radius */
}

There is no filled track left of the thumb: Chrome has no pseudo-element for it, so it would need a script. Ticks from a <datalist> are not drawn either.
