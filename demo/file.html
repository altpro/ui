File input

A native <input type="file" class="input"> for Blade and plain forms, and FileInput.vue: a drop zone round the same input, with the chosen files listed, previewed and removable. Neither uploads anything; the app sends the files and hands back progress and errors.

Drop zone

Click, press Enter or Space, or drop files on it. The native input covers the zone, so keyboards and screen readers get the browser's own file button. With multiple, more files add to the list; without it, a new file replaces the old one. accept filters dropped files as the picker does. Images get a preview. Upload fakes progress and the server's errors for this demo.

<script setup>
import FileInput from "@altpro/ui/js/FileInput.vue";
const form = useForm({ photos: [] });
</script>

<div class="field">
  <label for="photos">Photos</label>
  <FileInput v-model="form.photos" id="photos" name="photos" accept="image/*" multiple
    :errors="form.errors" :progress="progress">
    <span>PNG or JPEG, up to 5 MB each.</span>
  </FileInput>
</div>

Native input

.input on <input type="file"> draws the browser's file button as a muted button inside the border. Sizes, invalid and disabled work as on any input. In Laravel, <x-ui::field type="file"> writes it.
