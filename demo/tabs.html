Tabs

.tabs on a nav of links, one page per tab, or on a div of labels with radios that switch panels below. No JavaScript. The active bar is --tabs-active, the primary colour by default.

Links

Code Pull requests 1 Agents Actions Security and quality Insights 
<nav class="tabs" aria-label="Repository">
  <a href="/code" aria-current="page"><svg class="size-4" aria-hidden="true">…</svg> Code</a>
  <a href="/pulls">Pull requests <span class="badge">1</span></a>
</nav>

aria-current="page" marks the current tab. An icon before the text and a .badge count after it are optional.

Panels

The overview panel. Click a tab or focus one and press the arrow keys; the panels swap in place.

Three plans. The count in the tab is a .badge.

A panel can be any element, as long as it comes after the labels.

<div class="tabs">
  <label><input type="radio" name="plan" checked> Overview</label>
  <label><input type="radio" name="plan"> Pricing</label>
  <div>Overview panel</div>
  <div>Pricing panel</div>
</div>

Radios in labels, one name per group, checked on the starting tab. Panels follow the labels in the same order: the first non-label child belongs to the first label. Up to eight tabs.
