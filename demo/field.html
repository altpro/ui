Field

A .field stacks a label, a control, a .hint and an .error. The control is any .input: text, number, date, select, textarea. Addons (£, kg, an icon) go inside an .input wrapper.

Input

On its own, .input needs a name from somewhere: a visible <label for> or an aria-label. Sizes match the button so the two line up in a join. A select uses appearance: base-select where supported, so the chevron and the picker are styled; elsewhere it stays native.

<input class="input" type="search" placeholder="Search" aria-label="Search">
<select class="input sm" aria-label="Sort by">…</select>
<input class="input" type="email" aria-invalid="true" aria-label="Email">

Field

Label, control, hint. Point aria-describedby at the hint so it is read with the control. Children are styled by element, so the label needs no class.

Shown on your profile and in comments.

Up to 200 characters.

<div class="field">
  <label for="name">Display name</label>
  <input class="input" id="name" type="text" aria-describedby="name-hint">
  <p class="hint" id="name-hint">Shown on your profile and in comments.</p>
</div>

Errors

Three things turn the control red: a non-empty .error child, aria-invalid="true" on the control, or native validation failing after the user has touched it. Set aria-invalid and aria-describedby too, so the state and the message reach screen readers. An empty .error is hidden, so a template can always render it.

Enter a full email address.

  • At least 8 characters.
  • At least one number.

Tab through this without typing and it turns red on its own.

<div class="field">
  <label for="email">Email</label>
  <input class="input" id="email" type="email" aria-invalid="true" aria-describedby="email-error">
  <p class="error" id="email-error">Enter a full email address.</p>
</div>

Addons

Put .input on a <label> that wraps the control. A symbol, unit or icon beside it sits inside the same border and the focus ring goes round the lot. Clicking the addon focuses the control. A button next to an input is still a join.

Over your limit of 50.

<div class="field">
  <label for="price">Price</label>
  <label class="input"><span>£</span><input id="price" type="number"></label>
</div>

Beside a button

Each size is the same height as the button of that size.

Disabled

A disabled control dims itself and its label. The hint stays readable, since it often says why. A <fieldset class="field" disabled> disables everything inside it natively, no per-control attribute needed.

Cannot be changed after sign-up.

Managed by your admin.

<fieldset class="field" disabled>
  <label for="team">Team</label>
  <input class="input" id="team" type="text" value="platform">
</fieldset>
