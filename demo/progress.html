Progress and meter

.progress on a native <progress>, .meter on a native <meter>. The browser owns the value and the semantics; nui draws the track and the bar. No JavaScript.

Progress

Every bar needs a name: a <label for> or an aria-label. A label with the value in an <output> gives sighted users the number too.

<div class="field">
  <label for="upload" class="flex justify-between">Uploading photos <output for="upload">45%</output></label>
  <progress class="progress" id="upload" value="45" max="100"></progress>
</div>

<progress class="progress" aria-label="Loading"></progress>   <!-- no value: indeterminate -->

Colours

The same colour words as the button. No word is primary.

(none) secondary info success warning danger

Sizes

sm (default) lg

Meter

A value within a known range: storage used, password strength, a score. low, high and optimum put the value in a band, and the bar colour follows: success, warning, danger. A colour word pins one colour instead.

<!-- optimum="0": low values are good, so past `high` the bar turns red -->
<meter class="meter" id="disk" value="45" min="0" max="64" low="32" high="52" optimum="0"></meter>

<!-- one colour, whatever the value -->
<meter class="meter info" value="7" min="0" max="10" aria-label="Score"></meter>

Custom properties

Shared by .progress and .meter.

.progress, .meter {
  --progress-bg      /* track */
  --progress-fg      /* bar; a meter's bands override it unless a colour word is set */
  --progress-h       /* height, 0.5rem */
  --progress-radius  /* defaults to --radius */
}
