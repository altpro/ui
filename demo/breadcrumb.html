Breadcrumb

.breadcrumb on a <nav>. Links, then the current page as a <span aria-current="page">. Chevrons are drawn in CSS, so no separator markup.

Forms Breadcrumb

A <button> is styled like a link. Give it an aria-label and a popovertarget, and put the hidden levels in a .dropdown straight after it. The popover is in the top layer, so it gets no chevron.

<a href="/">Home</a>
<button type="button" popovertarget="crumbs" aria-label="Show hidden pages">
  <svg class="size-4" aria-hidden="true">…</svg>
</button>
<div id="crumbs" popover class="dropdown">
  <div class="nav"><a href="/docs">Docs</a><a href="/docs/components">Components</a></div>
</div>
