DataTable

DataTable.vue, for Inertia apps. Hand it an array and it searches, sorts and pages the rows itself. Hand it a Laravel paginator and the server has done that, through Altpro\Ui\TableQuery, so it renders what it was given and asks the server for the next page. Search, sort, page and filters live in the query string, so a table you are looking at is a link you can send. Page size and hidden columns are preferences and stay on the device.
