Loading

.skeleton stands in for content that has not arrived. .spinner is a turning ring for a short wait. loading on a .btn puts a spinner in front of the label. All CSS, no JavaScript.

Skeleton

A muted block, 1em tall by default, that shimmers. Size and round it with utilities to match what it replaces. The region it fills gets aria-busy="true" and one sr-only "Loading", so a screen reader hears one word rather than a pile of empty boxes.

Spinner

A ring in currentColor, so text-primary colours it. It has no text of its own: give it role="status" and an sr-only label, or put it next to visible text that says what is happening.

Loading button

loading on a .btn draws a spinner before the label. Add native disabled to stop pointer and keyboard activation, set aria-busy="true", and change the label to what is happening. The button keeps its colour and size, so nothing shifts around it. If the button holds an icon, drop it while loading, or two symbols sit in front of the label.

<button class="btn primary loading" disabled aria-busy="true">Saving</button>

Motion

With reduced motion on, the skeleton stops shimmering and sits still; the spinner is the signal itself, so it keeps turning at a third of the speed.

Custom properties

.skeleton {
  --skeleton-bg       /* the block */
  --skeleton-shine    /* the moving highlight */
  --skeleton-radius   /* --radius capped at 0.5rem */
}
.spinner {
  --spinner-size      /* 1.25rem; xs sm lg xl set it */
  --spinner-width     /* ring thickness, 2px */
}
