Tree

.tree on a <ul> of links and native <details>, for page hierarchies and category trees. A branch opens and closes with no script. Every row is a link or a toggle on the Tab order; it is not the ARIA tree widget.

Each branch here is a page too, so its link comes first and the <details> after it holds an empty <summary> named with aria-label. The summary sits on the chevron: the link navigates, the chevron toggles, and each is its own Tab stop. lines draws the guides. aria-current="page" marks the current page.

<nav aria-label="Pages">
  <ul class="tree lines">
    <li><a href="/">Home</a></li>
    <li>
      <a href="/about">About us</a>
      <details open>
        <summary aria-label="About us"></summary>
        <ul>
          <li><a href="/about/team" aria-current="page">Team</a></li>
          <li><a href="/about/history">History</a></li>
        </ul>
      </details>
    </li>
  </ul>
</nav>

A branch that is only a group puts its label in the <summary>. Leaves line up with branch labels. No lines, so levels are shown by indent alone. A trailing count gets ms-auto.

<ul class="tree">
  <li>
    <details open>
      <summary>Clothing</summary>
      <ul>
        <li><a href="/c/shirts" aria-current="page">Shirts <span class="badge sm ms-auto">23</span></a></li>
        <li><a href="/c/outerwear">Outerwear</a></li>
      </ul>
    </details>
  </li>
  <li><a href="/c/accessories">Accessories</a></li>
</ul>

Custom properties

.tree {
  --tree-fg --tree-chevron --tree-hover
  --tree-active-fg --tree-active-bg   /* aria-current row */
  --tree-line                         /* .lines guide colour */
  --tree-radius                       /* defaults to --radius */
  --tree-h --tree-gutter --tree-indent --tree-text
}
