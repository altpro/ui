Steps

.steps on an <ol>. Numbered markers joined by a line; each <li> carries its number in data-step. Mark the current step with aria-current="step"; everything before it is drawn as done, everything after as still to come. No done or todo classes, no JavaScript.

Horizontal

Done steps can be links back. The current and later steps are plain text.

  1. Cart
  2. Delivery
  3. Payment
  4. Review
<ol class="steps">
  <li data-step="1"><a href="/cart">Cart</a></li>
  <li data-step="2"><a href="/delivery">Delivery</a></li>
  <li data-step="3" aria-current="step">Payment</li>
  <li data-step="4">Review</li>
</ol>

Vertical

vertical stacks them. A one-line label sits on the marker's centre line. For a description, put it in a span class="block leading-normal muted" after the label.

  1. Order placed
  2. Paid
  3. DispatchedLeft the warehouse this morning.
  4. Delivered
<ol class="steps vertical">
  <li data-step="1"><a href="#">Order placed</a></li>
  <li data-step="2"><a href="#">Paid</a></li>
  <li data-step="3" aria-current="step">
    Dispatched
    <span class="block font-normal leading-normal muted">Left the warehouse this morning.</span>
  </li>
  <li data-step="4">Delivered</li>
</ol>

Custom properties

.steps {
  --steps-fg          /* label text, muted */
  --steps-marker-bg   /* upcoming marker */
  --steps-marker-fg
  --steps-active-bg   /* done and current markers, and the line between done steps */
  --steps-active-fg
  --steps-line        /* the line to an upcoming step */
  --steps-marker      /* marker size, 2rem */
}
