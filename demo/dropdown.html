Dropdown

.dropdown on a popover element makes a panel anchored to the button that opens it. Native popover and CSS anchor positioning, no JavaScript. Drops down, flips to stay on screen.

Menu

A .nav inside is a menu. Use a <div class="nav"> rather than <nav> for actions; <button> items work the same as links. The left trigger opens left-aligned. The avatar trigger is pinned right; at the edge of the page it would flip to right-aligned even without the pin.

Forms and help

Anything else gets 1rem padding. A small form works as a status switcher. An info button can open a longer description than a tooltip would hold. Width is max-content up to 24rem; set it with w-64 or similar.

Pinned placement

left right up down pin one axis. The other axis still flips if it must. Pin both and it never flips. Whatever the pins, if nothing fits the panel scrolls inside rather than leaving the window. Scroll so a trigger sits at the bottom of the window and the unpinned ones open upwards.
