nui

An HTML and CSS component layer for Tailwind v4. Tailwind does layout. nui does the components.

Install

npm install github:<owner>/nui

Then in your app stylesheet:

@import "tailwindcss";
@import "nui";

/* optional overrides */
@theme {
  --color-primary: oklch(0.6 0.2 30);
  --color-primary-foreground: white;
}
:root { --radius: 9999px; }

How classes compose

One base class, then bare modifier words. Utilities still win when you need them.

<button class="btn primary lg">Save</button>
<a class="btn outlined danger sm">Delete</a>
<button class="btn primary w-full rounded-none">Tailwind overrides</button>
