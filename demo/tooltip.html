Tooltip

A data-tooltip attribute with one line of supplementary text. Shows above the element on hover and keyboard focus. No class, no JavaScript. Anything essential, longer than a line, or likely to cover nearby content belongs in a dropdown.

On anything

Buttons, badges, avatars, links, plain text. The tooltip is supplementary and is not read by screen readers, so an icon-only button still needs an aria-label; repeat the same words in both.

<button class="btn primary" data-tooltip="Saves and closes the editor">Save</button>
<button class="btn ghost" data-tooltip="Copy to clipboard" aria-label="Copy to clipboard">…</button>

Placement

Always above, centred on the element, up to 20rem wide. CSS cannot dismiss it with Escape, so reserve clear space above the trigger. It does not flip or slide, and an ancestor with overflow clips it. A dropdown handles those cases.

<button class="btn" data-tooltip="Short">Left edge</button>

Scheme regions

The bubble inverts the region's colours: page foreground as fill, page background as text. Custom properties: --tooltip-bg --tooltip-fg --tooltip-radius --tooltip-h --tooltip-px --tooltip-text --tooltip-gap --tooltip-tail.
