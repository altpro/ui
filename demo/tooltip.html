Tooltip

A data-tooltip attribute with one line of text. Shows above the element on hover and keyboard focus. No class, no JavaScript. Anything longer than a line is a dropdown.

On anything

Buttons, badges, avatars, links, plain text. The tooltip is not read by screen readers, so an icon-only button still needs an aria-label; repeat the same words in both.

BS Last edited by Claude 
<button class="btn primary" data-tooltip="Saves and closes the editor">Save</button>
<button class="btn ghost" data-tooltip="Copy to clipboard" aria-label="Copy to clipboard">…</button>

Placement

Always above, centred on the element, up to 20rem wide. It does not flip or slide, and an ancestor with overflow clips it. Keep tooltips off the top edge of the page and out of scroll containers; a dropdown handles those.

<button class="btn" data-tooltip="Short">Left edge</button>

Scheme regions

The bubble inverts the region's colours: page foreground as fill, page background as text. Custom properties: --tooltip-bg --tooltip-fg --tooltip-radius --tooltip-h --tooltip-px --tooltip-text --tooltip-gap --tooltip-tail.
