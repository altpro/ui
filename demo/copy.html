Copy button

CopyButton.vue: a .btn that copies a value to the clipboard. Order numbers, tracking codes, emails. The tooltip names what it copies, then says "Copied" for two seconds, and a screen reader hears the same. Vue only; there is no CSS of its own.

After text

The default: a small ghost icon button. label is its accessible name and its tooltip.

<script setup>
import CopyButton from "@altpro/ui/js/CopyButton.vue";
</script>

Order ORD-1042 <CopyButton value="ORD-1042" label="Copy order number" />

Joined to a read-only input

Any class replaces the default look; outlined matches the input's border inside a .join.

<div class="join flex">
  <input class="input flex-1" id="tracking" readonly :value="order.tracking">
  <CopyButton class="outlined" :value="order.tracking" label="Copy tracking code" />
</div>

In a description list

The default slot replaces the icon. Start label with the slot's words so speech control users can say what they see.

<dd>INV-2026-0091 <CopyButton class="outlined xs" value="INV-2026-0091" label="Copy reference">Copy</CopyButton></dd>
