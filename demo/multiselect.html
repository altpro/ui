Multiselect

.multiselect: a button opening a .dropdown of checkboxes, in place of <select multiple>. One click ticks a box, the panel stays open, the button counts what is ticked, and the form submits the same values a multiple select would. Works without JavaScript; <ui-multiselect> keeps the count current.

Filters

The panel is at least as wide as the button. A long list stops at 20rem and scrolls.

 
<ui-multiselect class="multiselect">
  <button type="button" class="input" popovertarget="size"><span>Size</span></button>
  <fieldset id="size" popover class="dropdown" aria-label="Size">
    <label class="checkbox"><input type="checkbox" name="size[]" value="s"> Small</label>
    <label class="checkbox"><input type="checkbox" name="size[]" value="m"> Medium</label>
  </fieldset>
</ui-multiselect>

Errors

There is no client-side required: Firefox stops taking clicks in the panel once its validation message points into it. Validate on the server. In a .field, a non-empty .error turns the button red as it does any .input.

Blade

options is value => label. name gets [] added so PHP receives every ticked value. Pass old() to selected to refill the boxes after a failed validation. Other attributes, such as class, land on the wrapper.

<x-ui::multiselect name="size" label="Size"
    :options="['s' => 'Small', 'm' => 'Medium', 'l' => 'Large']"
    :selected="old('size', $product->sizes)" />

Vue

v-model is an array of the ticked values. options is [{ value, label }]. name is only needed when a real form submits it.

<script setup>
import Multiselect from "@altpro/ui/js/Multiselect.vue";
const sizes = ref(["m"]);
</script>

<Multiselect v-model="sizes" name="size" label="Size" :options="[
  { value: 's', label: 'Small' },
  { value: 'm', label: 'Medium' },
  { value: 'l', label: 'Large' },
]" />
