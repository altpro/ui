Multiselect

.multiselect: a button opening a .dropdown of checkboxes, in place of <select multiple>. One click ticks a box and the panel stays open. The button shows what is ticked, as a select shows its value: empty when nothing is, then the items separated by commas, then an ellipsis and a count once they no longer fit. The form submits the same values a multiple select would. Works without JavaScript; <ui-multiselect> keeps the button current.

Filters

The button has a fixed width, 12rem unless a utility on the wrapper changes it. The visible label sits outside, as it would for a select; the button repeats it as sr-only text, so its name is the label then the ticked items. A <label for> would replace that name and hide the items. The panel is at least as wide as the button. A long list stops at 20rem and scrolls.

 
<div class="field">
  <label>Size</label>
  <ui-multiselect class="multiselect">
    <button type="button" class="input" popovertarget="size" data-count="1">
      <span class="sr-only">Size</span><span><span hidden>Small</span><span>Medium</span></span>
    </button>
    <fieldset id="size" popover class="dropdown" aria-label="Size">
      <label class="checkbox"><input type="checkbox" name="size[]" value="s"> Small</label>
      <label class="checkbox"><input type="checkbox" name="size[]" value="m" checked> Medium</label>
    </fieldset>
  </ui-multiselect>
</div>

Validation

<ui-multiselect> is form-associated, so it takes the attributes a select would. required stops the submit while nothing is ticked, with the browser's own message on the button, and the button turns red once the user has changed it or tried to submit. max disables the unticked boxes once that many are ticked; say so in a hint. form ties it to a form elsewhere on the page; put it on each box too, so they submit with that form. disabled goes on the button and the panel, autofocus on the button. The Blade and Vue components take all of these as props and put each in the right place.

Up to two.

 
<ui-multiselect class="multiselect" required max="2">…</ui-multiselect>
<x-ui::multiselect name="days" label="Delivery days" required max="2" :options="$days" />
<Multiselect v-model="days" label="Delivery days" required :max="2" :options="days" />

Validate on the server as well. In a .field, a non-empty .error turns the button red as it does any .input.

Choose at least one delivery day.

Blade

options is value => label. name gets [] added so PHP receives every ticked value. Pass old() to selected to refill the boxes after a failed validation. Other attributes, such as class, land on the wrapper.

<x-ui::multiselect name="size" label="Size"
    :options="['s' => 'Small', 'm' => 'Medium', 'l' => 'Large']"
    :selected="old('size', $product->sizes)"
    required max="2" />

Vue

v-model is an array of the ticked values. options is [{ value, label }]. name is only needed when a real form submits it. The first is required with :max="2"; the second is disabled.

<script setup>
import Multiselect from "@altpro/ui/js/Multiselect.vue";
const sizes = ref(["m"]);
</script>

<Multiselect v-model="sizes" name="size" label="Size" :options="[
  { value: 's', label: 'Small' },
  { value: 'm', label: 'Medium' },
  { value: 'l', label: 'Large' },
]" required :max="2" />
