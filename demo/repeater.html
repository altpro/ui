Repeater

Repeater.vue: rows the user adds, removes and reorders. Order lines, contact methods, product attributes. Each row is a .card with its title and move and remove buttons; the row's fields come from the slot. Vue only.

Order lines

make returns the row "Add" appends. item names a row in its title and the button labels, and a screen reader hears each add, move and remove.

<script setup>
import Field from "@ui/Field.vue";
import Repeater from "@ui/Repeater.vue";
const form = useForm({ lines: props.order.lines });
</script>

<Repeater v-model="form.lines" name="lines" item="line"
  :make="() => ({ product: '', qty: 1 })"
  :errors="form.errors" :disabled="form.processing"
  v-slot="{ row, index, errors }">
  <Field v-model="row.product" :name="`lines.${index}.product`"
    label="Product" :errors="errors" />
  <Field v-model="row.qty" :name="`lines.${index}.qty`"
    label="Quantity" type="number" :errors="errors" />
</Repeater>

Server errors

Errors arrive keyed by position, lines.1.qty, then belong to the row: move it and they go with it, remove it and they go. An error on lines itself shows under the list.
