Pagination

A pattern, not a class. A <nav aria-label="Pagination"> holding .btn links, joined or spaced. The current page is aria-current="page" plus primary; the first and last page disable their arrow with aria-disabled="true".

Joined

One bar of outlined buttons in a .join. Arrow links are icon-only, so they carry an aria-label. Ellipsis is a plain span with pointer-events-none.

1 2 3 … 12 
<nav class="join" aria-label="Pagination">
  <a class="btn outlined" role="link" aria-label="Previous page" aria-disabled="true">
    <svg class="size-4" aria-hidden="true">…</svg>
  </a>
  <a href="?page=1" class="btn primary" aria-current="page">1</a>
  <a href="?page=2" class="btn outlined">2</a>
  <a href="?page=3" class="btn outlined">3</a>
  <span class="btn outlined pointer-events-none">…</span>
  <a href="?page=12" class="btn outlined">12</a>
  <a href="?page=2" class="btn outlined" aria-label="Next page">
    <svg class="size-4" aria-hidden="true">…</svg>
  </a>
</nav>

Spaced

The same links as ghost buttons in a flex gap-1. Lighter, suits a page footer.

1 2 3 4 5 … 12 
<nav class="flex flex-wrap items-center gap-1" aria-label="Pagination">
  <a href="?page=2" class="btn ghost" aria-label="Previous page">…</a>
  <a href="?page=1" class="btn ghost">1</a>
  <a href="?page=3" class="btn primary" aria-current="page">3</a>
  …
</nav>

Previous and next only

For a feed or a blog where the page count does not matter. Labels instead of numbers, justify-between pushes them to the edges.

Table footer

A row count, a page size select and a compact first, previous, next, last bar. Small sizes match a table sm. This is a div, not a nav, because the select is a control rather than a link.

Showing 21 to 40 of 236

Page 2 of 12

<div class="flex flex-wrap items-center gap-4 text-sm">
  <p class="muted">Showing 21 to 40 of 236</p>
  <label class="ml-auto flex items-center gap-2">
    Rows per page <select class="input sm">…</select>
  </label>
  <p aria-live="polite">Page 2 of 12</p>
  <nav class="join" aria-label="Pagination">
    <a href="?page=1" class="btn outlined sm" aria-label="First page">…</a>
    <a href="?page=1" class="btn outlined sm" aria-label="Previous page">…</a>
    <a href="?page=3" class="btn outlined sm" aria-label="Next page">…</a>
    <a href="?page=12" class="btn outlined sm" aria-label="Last page">…</a>
  </nav>
</div>

Buttons instead of links

When a script fetches the page in place, use <button type="button"> and the real disabled attribute. Same classes. Keep the nav so the landmark survives.
