Toast

A .toaster region fixed in a corner, present and empty from page load. The app appends an .alert to it. Each one slides in, lives for six seconds, then fades; hover or focus pauses the clock. The only JavaScript is the append and the removal.

Colours

<div id="toaster" class="toaster" role="region" aria-label="Notifications" aria-live="polite"></div>

<script>
  const toast = (html, cls = "") => {
    const el = Object.assign(document.createElement("div"), { className: `alert ${cls}`, innerHTML: html });
    el.addEventListener("animationend", (e) => e.animationName === "toast-life" && el.remove());
    toaster.append(el);
  };
  toast("<p>Your changes have been saved.</p>", "success");
</script>

Shapes

A toast with an action or a dismiss cross is a btn ghost xs inside the alert, same as a dismissible alert. pinned turns the clock off: anything the user must act on or read stays until they close it.

Corners

top and start on the region. One region per page; this demo moves it so every corner can be tried.
