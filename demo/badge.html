Hues

Every Tailwind hue name is a modifier here too, the same set the avatar takes. Use these for tags and categories, and keep the semantic colours above for status.

red orange amber yellow lime green emerald teal cyan sky blue indigo violet purple fuchsia pink rose
red orange amber yellow lime green emerald teal cyan sky blue indigo violet purple fuchsia pink rose

A hue is a tint in light and a deep shade in dark. Text and outline colours are derived from the fill, so every hue stays above 4.5:1 in both schemes and in every style.

<span class="badge teal">Design</span>
<span class="badge outlined violet sm">Beta</span>

Link badge

Icons are size-3. A link or button badge gets hover, a focus ring and a pointer. Keep it at the default size or larger so it meets the 24px target minimum.
