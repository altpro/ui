Timeline

.timeline on an <ol>. A dot per event joined by a line, for an audit history or an activity feed. Every event has happened, so unlike Steps there is no current or done state. No JavaScript.

Audit history

Each item is what happened and a <time> for when. A one-line entry sits on the dot's centre line; longer text wraps under it.

  1. Steve Rayner changed the price from £12.00 to £14.00

    Today, 09:30

  2. Ann Okafor added the product to the Autumn collection

    Yesterday, 16:05

  3. Ann Okafor updated the description. The new copy mentions the recycled packaging and drops the line about limited stock.

    12 Sep, 11:20

  4. Steve Rayner created the product

    1 Sep, 08:00

Activity feed

Notes, attachments and field changes on a record. A <blockquote> is a note. A field change is <del> old, <ins> new: the old value is muted and struck through, the new one bold. An attachment is a link to the file, its size in a .muted span.

  1. Steve Rayner changed Status Pending → Paid

    Today, 09:30
  2. AO

    Ann Okafor left a note

    Customer rang to say the courier left it with a neighbour at number 14. Happy for us to close this.
    Yesterday, 16:05
  3. SR

    Steve Rayner attached invoice-1042.pdf 84 KB

    12 Sep, 11:20

  4. Ann Okafor changed Delivery Standard → Next day and Total £42.00 → £48.95

    12 Sep, 10:02

  5. Order placed

    11 Sep, 19:47

Custom properties

.timeline {
  --timeline-dot      /* the dot, muted-foreground; colour words on an item set it */
  --timeline-line     /* the line between dots, border */
  --timeline-marker   /* marker square and one-line height, 1.5rem */
}
